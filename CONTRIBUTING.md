# Contributing

## Reporting errors or suggesting changes

If you find a mistake, outdated information, or want to suggest an improvement, open an issue in this repository.

Include:
- What is wrong or unclear
- Where it appears (section title or line)
- What the correct or improved version should say

For questions about the Metry platform or the MCP server itself, reach us at [feedback@metry.io](mailto:feedback@metry.io).
